How this listing works

Events are records

Each event is a community.lexicon.calendar.event record published from @cultureblocs.com. This page reads them from the repository as you load it, so a correction appears here without a site deploy.

Your visit is yours

Went to something? Write a visit bead in your own repository and reference the event by its at:// address — open Details on any event to copy it — or just press I went, which writes it for you. The memory stays with you; the event is just what it points at.
