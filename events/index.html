Programmes you can point at.

Each directory is a cultural programme — a festival, an art week, a season — published as open calendar records. Anyone who goes can write a bead in their own repository that references the event, so the memory stays theirs and the programme gains a trail of who was there.

How a directory is made

The events are community.lexicon.calendar.event records — the shared calendar schema, not a CultureBlocs one — so any calendar app on the network can read them too. A directory page is a folder here with a listing of which records belong to it; the page reads the records themselves live from the publisher's repository.
